# BABEL — Quick Rules Reference (Canon v0.1)

## Turn
**Draw 1 tile → Place → Resolve resources/buildings → Take 1 action.**

Actions: **Build / Babel / Attack / Muster / Scheme / Barter / Pass**.

## Terrain
- Farmland → Food
- Forest → Wood
- Hills → Brick
- Mountain → Metal
- Desert → nothing

Placement payout = **1 + adjacent matching terrain**.

A Host anywhere in a connected feature shuts down that whole feature's resource payout and harvesting buildings.

## Harvesting buildings
Sawmill / Farmstead / Brickworks / Mine.

When another player expands your building's feature:
- placer gets normal payout;
- you get the same payout;
- placer gets **+1 extra matching resource total** if any foreign harvester triggered.

One matching harvester per player per connected feature.

## Babel
Cost per piece:
- Stage I: 2 Brick + 1 Food
- Stage II: 4 Brick + 1 Food
- Stage III: 6 Brick + 2 Food

Prestige: **2 / 3 / 4** by Stage.

Host reaches Babel → remove newest piece and Host. At 0 pieces, first Host occupies Foundation; second Host arriving while occupied = shared loss.

## Heaven
Existing Hosts move, resolve Babel impacts, then each Beacon spawns one Host.

Ophanim Host: Move 1, 1 hit.

Stage III: ~25% Seraphs — Move 2, Shield 1 (2 successful hits total).

## Army
Start with **1 Army die**. Muster: **1 Food + 1 Metal → +1 Army die**, max 5.

Attack: roll Army dice. Each die is **d6 + 2 vs Host Defence**. Assign successful dice among any Hosts. One success = one hit.

## Towers
Cost: **2 Wood + 1 Metal**. One per connected feature.

During any player's Attack action, each occupied Tower feature adds **1 targeted support die** against a Host in that feature. Same d6+2 test.

Tower owner gets **+1 Prestige per successful support hit**.

## Walls
Build action: **1 Wood → 2 Wall edges**.

Host crossing Wall spends that movement destroying it and stays put. A Move-2 Seraph can break it then continue with its second movement.

## Rivers
River edges must connect. River tiles/Lakes are impassable to Heaven. Beacons cannot be placed on them.

## Scheme deck — 6 cards
2× False Prophet — redirect one Host for a phase.  
2× Common Tongue — cancel Confusion.  
2× Frenzied Works — take one extra non-Scheme action.

Buy blind: **1 Food + 1 Metal**.

## Confusion
Stage I: 2× Silent Workshops, 2× Lost Ledgers, 2× Fractured Command.  
Stage II adds Stalled Works + March of Heaven.  
Stage III adds Broken Swords.
