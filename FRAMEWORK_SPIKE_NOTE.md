# Framework spike note — 2026-09-15

`boardgame.io` remains a relevant candidate because it provides turn-based state management, phases, multiplayer, React bindings and logs. However, its npm `latest` is currently 0.50.2 and npm reports that release as about four years old. The GitHub project has had maintenance activity in 2026, including release-publishing workflow work, so it is not simply abandoned, but the package cadence warrants caution.

Treat it as a short spike, not a mandatory architectural foundation.
