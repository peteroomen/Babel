# First playable acceptance criteria

A milestone-5 build is a successful first playable if a human group can complete a game without developer intervention and answer all of these from the UI:

- Whose turn is it?
- What terrain tile did I draw and where can it legally go?
- What resource payout will this placement produce?
- Which other players/buildings trigger from it?
- Which geographic features are occupied and therefore shut down?
- What actions can I legally take now?
- How close is Babel to the next permanent escalation?
- Where can the next Beacon legally be placed?
- Where will each Host move and why?
- Which Walls will be broken?
- Which Towers support my Attack?
- How many Army/Tower dice am I rolling and where are hits assigned?
- What does the current Confusion card change?
- How much Prestige does everyone have and what generated it?
- Why did humanity win or lose?

## Feel goals

The prototype should regularly create moments like:

- “If you expand that Forest, we both get rich.”
- “Don't put the Beacon there; that's our entire Brick economy.”
- “I can build Babel or save the farm, not both.”
- “We should wait before triggering the next Stage.”
- “You selfish bastard, we needed that Metal for the army.”
- “The Wall bought us exactly one round.”
- “The Tower broke the Seraph's shield; finish it.”

If those moments do not emerge, do not solve the problem with more content first. Revisit the core rules/UX.
